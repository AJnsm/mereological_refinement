# Empirical results

Open `reproduce_empirical_results.ipynb` and run all cells with Python 3.11.
Install dependencies with `pip install -r requirements.txt`.

The notebook displays the three main-text results and does not save output files.
Keep the bundled `data/sachs_zenodo.zip` beside it. Data: Sachs et al.,
[Zenodo](https://doi.org/10.5281/zenodo.7681811), CC BY 4.0.
